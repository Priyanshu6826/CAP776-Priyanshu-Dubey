### About This Project

This project is part of the **CAP776 - My Data, My Story** course. It involves tracking daily personal activities (sleep, fitness, study, coding, etc.) over a 40-day period and analyzing the data using Python.

### What It Does

- **Reads** daily activity data from an Excel file (`*.xlsx`)
- **Validates** all data entries for completeness and correctness
- **Computes** key indices:
  - Tech Productivity Index (TPI)
  - Academic Activity Index (AAI)
  - Physical Activity Index (PhAI)
  - Sleep & Recovery Index (SRI)
  - Activity Balance Index (ABI)
  - Time Utilization Index (TUI)
  - Experience Index (EI)
  - Data Continuity Index (DCI)
  - **Personal Activity Index (PAI)**
- **Calculates** correlations between:
  - Sleep vs Energy
  - Study vs Satisfaction
  - Coding vs Energy
- **Generates** a comprehensive intelligence report

### Files

| File | Description |
|------|-------------|
| `main.py` | Core analysis script |
| `*.xlsx` | Daily activity tracking spreadsheet |
| `*.docx` | Final project report |

### How to Run

```bash
pip install openpyxl
python main.py
```

### Data Tracked (Daily)

- Sleep (minutes)
- Fitness (minutes)
- Study (minutes)
- Coding (minutes)
- Class attendance (minutes)
- Other activities (minutes)
- Day's feeling (Excellent/Good/Neutral/Low/Stressed)
- Satisfaction level
- Energy level
